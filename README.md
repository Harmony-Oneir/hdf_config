# hdf_config
Репозиторий `hdf_config` содержит конфигурацию драйверного фреймворка HDF для продукта oneir и оформлен как самостоятельный компонент `oneir_hdf_config` подсистемы oneir. Из исходных файлов `hdf.hcs` и `device_info.hcs` с помощью утилиты hc-gen (компонент `drivers_tools`) собираются два артефакта: бинарная конфигурация `hdf_default.hcb` со списком хостов, устройств и драйверов, которую читают `hdf_devmgr` и процессы `hdf_devhost`, и init-конфиг `hdf_devhost.cfg` с командами запуска хостов, их пользователями, группами и привилегиями.

# Сборка

Для сборки используйте команду `./make.sh --reload //oneir/hdf_config/uhdf:hdf_config` в контейнере. Результат сборки находится по пути `out/oneir/gen/oneir/hdf_config/uhdf/`:
| Файл | Описание |
|---|---|
| `hdf_default.hcb` | Скомпилированная конфигурация HDF (бинарный вид `hdf.hcs` + `device_info.hcs`): список хостов, устройств и драйверов. Читается `hdf_devmgr` и хостами при старте, ставится в `/vendor/etc/hdfconfig/` |
| `hdf_devhost.cfg` | Init-конфиг, сгенерированный из той же `hdf.hcs`: команды запуска процессов `hdf_devhost` для каждого хоста (сейчас только `allocator_host`), с пользователем, группами, capabilities и приоритетами. Ставится в каталог `init` |
